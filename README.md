## 为什么不用 PE

周期股的当期 PE 会在盈利顶部变得极低。看招商轮船 2026-10-29：

| 指标 | 数值 | 近 10 年分位 | 看起来 |
|---|---:|---:|---|
| PE(TTM) | 9.45 | **8%** | 十年最便宜 |
| PB | 2.76 | **94%** | 十年最贵 |
| 盈利位置 | 2.69 | — | 盈利是中位数的 2.7 倍 |

**同一只股票，PE 说便宜，PB 说贵。**

因为 PE 的分母（盈利）在周期顶部，而 PB 的分母（净资产）不会。用中位盈利算，它的**正常化 PE 是 74.3 倍**，而不是 9.45。

水运板块最能说明问题——PE 分位最低的三只，PB 分位最高：

| 名称 | PE | PE分位 | PB | PB分位 | 判断 |
|---|---:|---:|---:|---:|---|
| 中远海特 | 10.19 | **2%** | 1.72 | **98%** | 周期顶 |
| 招商轮船 | 9.45 | **8%** | 2.76 | **94%** | 周期顶 |
| 中远海能 | 11.62 | **8%** | 1.99 | **83%** | 周期顶 |

## 三个核心指标

| 指标 | 算法 | 回答的问题 |
|---|---|---|
| **PB 分位** | 当前 PB 在近 130 个月里的位置（要求 ≥60 个月） | 现在是贵还是便宜 |
| **盈利位置** | 最新扣非 TTM ÷ 中位扣非 TTM | 盈利是不是在周期顶 |
| **正常化 PE** | 总市值 ÷ 中位扣非 TTM | 如果盈利回到常态，这值多少钱 |

**盈利位置给了两个口径：10 年和 5 年。** 两个差得越多，说明行业结构变了。

铝行业实测（2017 年产能封顶后利润中枢上移）：

| 公司 | 10 年口径 | 5 年口径 | 差 |
|---|---:|---:|---:|
| 中国铝业 | 6.19 | **2.63** | **−3.56** |
| 中孚实业 | 16.53 | **3.61** | **−12.92** |
| 天山铝业 | 4.14 | **2.10** | −2.04 |
| 华峰铝业（加工） | 1.54 | 1.10 | −0.44 |

电解铝差 1.4~12.9，加工厂只差 0.4~0.6。**差距本身就是"行业结构变了"的信号。**

> ⚠️ 工具**不知道**任何产业政策（产能天花板、去产能、开采配额）。
> 它只能把这个差距摆出来，让你自己判断用哪个口径。

## 判断分五类

```
周期顶（PB贵+盈利高）   PB 分位 ≥70 且 盈利位置 ≥1.5
周期底（PB便宜+盈利低） PB 分位 ≤30 且 盈利位置 ≤0.7
PB 便宜 / PB 偏贵       单看 PB 分位
中性                    其余
```

**另有三种「不给结论」的状态**，各自说清原因：

| 标签 | 含义 |
|---|---|
| **历史不可比** | 中位利润为负或接近 0（重组、壳公司、连年亏损）。任何纵向比较都不成立。 |
| **历史不足5年** | PB 观测不足 60 个月。次新股只有「上市以来」的历史，而上市初期估值最高，现在的 PB 相对那时永远显得便宜。 |
| **·盈利存疑** | 盈利数据不可信（见下节）。标签只基于 PB 那一半依据。 |

## 数据可信度：什么时候不给结论

盈利侧的判断依赖「中位数」，而中位数在两种情况下不可靠：

**① 样本量不足**　用季报还原成滚动 12 个月（TTM），每只股票约 35~38 个观测。
　　中位数的相对标准误 ≈ `1.25 × 变异系数 / √n`，超过 60% 判定不可信。

**② 波动过大**　变异系数 = 扣非利润标准差 ÷ |中位数|。

| 公司 | 中位利润 | 变异系数 | 结论 |
|---|---:|---:|---|
| 株冶集团 | 0.90 亿 | 7.34 | 不可信 |
| 云铝股份 | 28.8 亿 | 1.13 | 可信 |
| 天山铝业 | 18.8 亿 | 0.97 | 可信 |

> **为什么不用「中位利润 < 1 亿」这种绝对门槛？**
> 中位利润分布是 P25=0.5 亿、P50=1.4 亿、P75=4.0 亿。把门槛从 0.5 亿调到 3 亿，
> 不可信比例会从 11% 涨到 57%——**门限决定结论**。所以改用无量纲的变异系数。

判定不可信时，标签会变成「PB 便宜·盈利存疑」这类，**不假装给出完整结论**。

## 产业链五类

按**主营业务原文**的关键词判定，鼠标悬停可看原文：

```
上游资源 / 中游冶炼 / 下游制造 / 运营服务 / 一体化 / 其他
```

这个维度解释了为什么同一行业内部估值分位会反向。铝行业实测：

| 链条 | 只数 | PB分位中位 | 毛利率 | 盈利波动 |
|---|---:|---:|---:|---:|
| 一体化（云铝、南山、中铝、神火） | 6 | **64%** | 22% | 5.2 |
| 下游制造（华峰、明泰、亚太、创新新材） | 13 | **23%** | 10% | 2.7 |

**上游在商品涨价时先受益，下游的毛利同时被挤压，两边估值分位天然反向。**

> ⚠️ 但**全市场**看这个规律不明显（上游 42 / 下游 39 / 一体化 37）。
> 产业链位置只在**同一行业内**可比，不能当全市场因子用。

**分类的边界问题**（已知）：
- `!` 表示主营业务描述和行业对不上，多半是借壳/重组后没更新（天山铝业的描述至今还写着「泵及控制设备」）
- 关键词无法区分「拥有资源」和「给资源方打工」的所有情形——中油工程（油气工程承包商）曾被误判为资源公司，已修

## 行业适用性：哪些行业会被剔除

如果**一个行业里超过一半的标的都「无法判断」**，说明这套纵向估值法对它本来就不成立，整个行业剔除。

实测只有半导体越线：

| 行业 | 只数 | 无法判断占比 |
|---|---:|---:|
| **半导体** | 168 | **58%** |
| 汽车整车 | 20 | 40% |
| 船舶 | 8 | 38% |
| 全市场 | — | 30% |

半导体被剔除的直接原因是**次新占比 73%**（上市中位 4.9 年）；更根本的原因是它同时具备成长和周期属性——**利润创新高对铜铝是「周期顶」，对芯片可能只是「利润在扩张」**。

用 `--all` 可以包含回来。

## 用法

```bash
# 最便宜在前（PB 分位）
python -m cyclical -n 20

# 最贵在前 —— 找陷阱用这个
python -m cyclical -s pb_desc -n 20

# 看单个行业
python -m cyclical -i 铝 -n 20
python -m cyclical -i "铜,铝,黄金,小金属"

# 包含被剔除的行业
python -m cyclical --all -i 半导体 -n 20

# 生成 HTML 面板 / 导出 CSV
python -m cyclical --html output/cyclical.html
python -m cyclical --csv output/cyclical.csv
```

| 参数 | 说明 |
|---|---|
| `-i, --industry` | 行业名，逗号分隔 |
| `-n, --top` | 显示前 N 只（默认 30） |
| `-s, --sort` | `pb_asc` / `pb_desc` / `earn` / `pe_asc` |
| `--min-cap` | 最小市值（亿），默认 50 |
| `--all` | 包含无法判断 ≥50% 的行业 |
| `--html` / `--csv` | 输出面板 / 表格 |

**面板交互**：行业下拉 + **板块下拉**（沪市主板 / 深市主板 / 创业板 / 科创板 / 北交所）+ 代码名称搜索 + 标签筛选，四者可叠加；点表头排序。

## 已知局限

1. **不知道任何产业政策** —— 产能天花板、去产能、开采配额都不在算法里。工具只能用 10 年/5 年双口径把这个差异摆出来。
2. **PB 分位不能跨公司比** —— 它是纵向的。铝行业里华峰 1% 和云铝 74% 不矛盾，原因是产业链位置不同。
3. **中位利润会漂移** —— 扩产型公司的「中位」天然偏低。
4. **无法区分「周期」和「成长」** —— 这是半导体被剔除的根本原因，也没有通用解法。
5. **分红政策变化会扭曲 PB** —— 大额分红让净资产下降、PB 上升，看起来像"变贵"，其实什么都没变。未做自动检测。
6. **不给买卖建议** —— 工具给的是「位置」，不是「时点」。周期顶不代表马上下跌，它可能在高位待两年。
